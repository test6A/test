# 马来PC多币种下单——变更模块与功能点

> 基于《马来PC多币种下单——完整产品方案说明书 V1.0.html》整理
>
> 核心方案：PC 保持结算口径稳定（USD），前台支持按配置选择下单币种；订单创建时锁定下单金额、下单币种和汇率快照；汇率超过阈值后 7 天延迟生效并邮件通知业务方。

---

## 一、Admin 后台配置模块

| 功能点 | 说明 |
|--------|------|
| 多币种国家配置 | 新增配置入口，按国家维护展示币种、汇率来源、波动阈值、缓冲天数、金额精度、邮件接收人、免责声明、启停状态 |
| 配置审计 | 所有新增、编辑、启停、汇率修正、通知人变更需记录操作人、时间、前后值 |
| 配置生效规则 | 新增启用需有生效汇率；停用后前台隐藏 MYR；修改阈值/缓冲天数影响后续同步判断 |

---

## 二、汇率同步与预警模块

| 功能点 | 说明 |
|--------|------|
| 定时同步汇率 | 拉取财务月度基准汇率，数据库持久化 + 缓存 |
| 汇率状态管理 | 状态流转：CURRENT / PENDING / EXPIRED / IGNORED / FAILED / CANCELLED |
| 波动阈值判断 | 偏差率 = \|新汇率 - 当前汇率\| / 当前汇率 × 100%，马来默认 3% |
| 7 天延迟生效 | 超过阈值 → 进入待生效状态，预计生效时间 = 同步时间 + 缓冲天数 |
| 覆盖/取消机制 | PENDING 期间新汇率覆盖重置缓冲，或 ≤ 阈值则取消待生效 |
| 邮件预警通知 | 超阈值时邮件通知销售/GTM/业务方；失败重试 3 次不阻塞生效 |
| 异常降级 | 同步失败保留旧汇率；无效数据过滤；缓存/数据库不可用降级 USD-only |

---

## 三、PC 前台下单流程模块

| 功能点 | 说明 |
|--------|------|
| 汇率横幅 | 页面顶部展示当前生效汇率、生效日期、免责声明及 MYR/USD 切换入口 |
| 产品列表页 | 产品单价、促销价、服务价、加购合计按展示币种格式化；切换币种只刷新展示不触发重新查询 |
| 购物车列表 | 商品金额、小计、合计按展示币种刷新；不锁定汇率；查看渠道购物车按渠道所属国家判断币种 |
| 订单结算页 | 商品/服务/运费/税费/返利/应付总额按当前汇率展示；返利弹窗增加 MYR 参考金额 |
| 订单确认页 | **锁定汇率快照**：锁定下单币种、汇率、汇率日期；展示 Locked 状态；返回修改后重新锁定 |
| 销售待下单（Pending Submission） | 销售创建待下单锁定金额口径；渠道办理/确认沿用同一锁定汇率 |
| 提交订单 | 保存下单币种、锁定汇率、汇率日期、订单金额展示口径 |

---

## 四、订单展示模块（Search Order）

| 功能点 | 说明 |
|--------|------|
| 订单列表 - All | 按订单记录币种展示金额、币种标识、锁定汇率；混合币种列表 |
| 订单列表 - Pending | 待提交/待审批/待付款列表按订单记录币种展示 |
| 订单列表 - Closed | 终态订单保留原币种和锁定汇率；Re-order 按新订单规则取汇率 |
| 订单详情 | 汇率横幅（Locked 状态）、Payment/Product/合计行按订单币种展示 |
| 筛选规则 | 金额筛选/排序/分页默认按 USD 主金额；新增 Display Currency 筛选项（可选） |
| 导出规则 | 保留 USD 主金额，补充展示币种、锁定汇率、汇率日期、MYR 参考金额、免责声明 |

---

## 五、订单审批模块

| 功能点 | 说明 |
|--------|------|
| PC 端审批 | 金额汇总、商品/服务明细按订单币种展示；展示锁定汇率和 Locked 状态 |
| 移动端审批 | 金额与 PC 一致；汇率信息可折叠但必须可查看 |
| 后台待办 | 待办列表金额列展示订单币种金额和币种标识 |

---

## 六、购物车分享与导出模块

| 功能点 | 说明 |
|--------|------|
| 分享购物车 | 只传商品、数量及明确支持的服务项；不锁定价格/汇率/库存/返利 |
| 接收方导入 | Add to Cart / Replace Cart 按接收方国家、合同、库存、当前汇率重新计算 |
| 查看渠道购物车 | 币种上下文随当前渠道重置 |
| 购物车导出 | 增加 MYR 参考金额、当前生效汇率、汇率日期、展示币种；标注"参考汇率/非结算金额" |

---

## 七、下游系统兼容模块

| 功能点 | 说明 |
|--------|------|
| CES 抛单 | USD 主字段必填；币种/汇率信息可选；异常不阻塞原主流程 |
| AI 导入 | 识别 MYR/RM/USD；MYR 导入按当前汇率反算 USD；汇率不可用时阻断 MYR 导入 |
| 返利展示 | 返利弹窗展示 MYR 参考金额；余额/选择/校验/扣减仍以 USD 为准 |

---

## 八、数据模型变更

| 模型 | 核心字段 |
|------|----------|
| **CurrencyConfig** | countryCode, settlementCurrency, displayCurrency, symbol, precision, thresholdPercent, bufferDays, disclaimer, emailReceivers, status |
| **ExchangeRateRecord** | currencyPair, rate, source, effectiveDate, status (CURRENT/PENDING...), estimatedEffectiveTime, deviationRate, batchId |
| **OrderExchangeSnapshot** | orderId, displayCurrency, symbol, exchangeRate, exchangeRateDate, exchangeRateSource, lockedAt, snapshotId |

---

**总结：共 8 大模块、30+ 功能点，核心逻辑是结算保持 USD 不变，前台按配置支持 MYR 展示/选择，订单提交时锁定汇率快照，汇率超阈值 7 天延迟生效并邮件通知。**
